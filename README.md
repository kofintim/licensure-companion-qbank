# Licensure Companion

[Open the practice simulator](https://kofintim.github.io/licensure-companion-qbank/)

An independent Step 2 CK–style clinical reasoning question bank based on the October 2026 edition of *The High-Yield Licensure Companion*. The original PDF is needed only for further reading.

## Practice

Start with a 15-question cardiology block, or choose **New test** to select subjects, individual topics, or a printed page range. Each block samples distinct cases from the matching pool. Smaller topics use their available cases. The bank contains 207 original cases covering 159 numbered topics across 12 subjects.

Each submission locks the answer and displays the reasoning for all five options, the source section, and both printed and PDF page numbers. The next unanswered case opens immediately. The navigator supports flagging and revisiting cases. The last submission opens the block audit.

## Track progress

The dashboard ranks attempted subjects and topics by latest-answer accuracy. It displays the number of distinct cases behind each percentage and lists missed concepts with reading references. **Practice missed questions** builds a block from the lowest-scoring field. **History** preserves original scores and resumes unfinished blocks.

Use the initials button to create or switch learners. Profiles and results live in the browser's local storage. Clearing site data removes them. Anyone using the same browser profile can open its learner records. No sign-in, cross-device synchronization, or personal data upload is used.

## Run locally

Open `index.html` in a modern browser, or serve this directory with `python -m http.server 8000` and open `http://localhost:8000`. GitHub Pages serves the same files from the main branch. There are no build dependencies.

## Source scope

Cases use the companion's clinical concepts with original patient scenarios. The question bank samples the text and includes Ghana-specific contexts where relevant. Percentages describe performance on this practice material. The software is independent of USMLE and NBME and is intended for study.
